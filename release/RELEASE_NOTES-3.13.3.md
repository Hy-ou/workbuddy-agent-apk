# WorkBuddy 3.13.3

DSH 布局改为**两种选择**：

1. **标准布局（默认）**：和以前一样，保留 DSH 顶栏、App 底部 6 Tab 与系统状态栏；
2. **沉浸全屏**：点 DSH 顶栏的「全屏使用」后进入，隐藏顶栏/底部导航/系统状态栏，
   页面顶到 y=0，顶部居中浮动「退出全屏」返回标准布局。

## 改动

- `AppShell`：`dshImmersive` 默认 `false`，删除「切到 DSH 引擎就强制全屏」的逻辑；
  切换引擎时回到标准布局，全屏只在本次会话内由用户主动进入。
- `DshScreen`：顶栏的「全屏使用」按钮保持不变；沉浸时显示「退出全屏」浮层；
  返回键优先退出全屏，再交给 App。
- 不再出现「一进 DSH 就被强制全屏、找不到底部导航」的情况。
