# WorkBuddy 3.5.0

新增通知推送、Shizuku 系统特权通道，以及扩展能力面板。

## 新增

- **AI 通知**：原生助手新增 `notify` 工具，任务完成/需要关注时推送到通知栏（只需通知权限）。
- **Shizuku 免 root 特权**：安装并授权 Shizuku 后，助手 `shell` 工具可执行系统命令
  （装应用、模拟输入、截屏、改系统设置）；未安装时自动降级，不影响其它功能。
- **扩展能力面板**（设置 → 扩展能力）：通知状态、Shizuku 状态与授权入口、
  工具链状态（node/npm/git/python）、**社区插件精选清单**（12 个 dsh 生态插件，
  一键复制包名到 DSH 控制台的插件面板安装）。

## 边界

- 「扩展中心」的 19 项工具链安装、社区插件一键安装，需要内核内置 npm/pnpm/git
  （精简包已剔除，约 +120 MB）与包管理器级实现，属于后续迭代。
- DSH 侧的 notify 工具需要额外插件包，本期仅在原生助手提供。

## 安装

```bash
adb install -r WorkBuddy-3.5.0.apk
```

## 校验

见附件 `SHA256SUMS`。
