# WorkBuddy 3.4.0

P2 宿主能力：插件开关、安全模式、备份/还原、我的补丁——把「DSH 内核坏了要清数据」的常见坑都补上。

## 新增

- **插件开关**：扫描内核树里的 `@deepseek-ai/dsh-*` 包，在「设置 → DSH 工具」逐个启用/禁用；
  `cordis.patch.yml` 每次启动由 App 重写（内置策略：sandbox、office-to-pdf、遥测）。
- **安全模式**：连续启动失败时，把 `dshhome/profiles` 旁置并从 payload 恢复出厂 profile 再启动，
  **会话与凭证不丢**；DSH 失败页与设置页均有入口，并显示连续失败次数与最后错误。
- **备份 / 还原**：经系统文件选择器导出/导入 zip（`dshhome`、原生助手会话、网关配置、我的补丁）；
  导入前自动把现有数据备份为 `dshhome.bak-<时间>`。
- **我的补丁**：首次解压记录内核树全量 sha256 基线；「保存修改为补丁」保存与出厂不同的
  文本/配置/图片（单个 ≤8 MB），启动时自动回放；「清空补丁」回出厂。

## 修复

- `cordis.patch.yml` 不再依赖旧标记判断，改为每次启动重新生成，插件开关即时生效（重启内核后）。

## 升级说明

直接覆盖安装即可；首次启动会为内核树生成基线（约 4.8 MB，几秒钟），不影响已有会话。

## 安装

```bash
adb install -r WorkBuddy-3.4.0.apk
```

## 校验

见附件 `SHA256SUMS`。
