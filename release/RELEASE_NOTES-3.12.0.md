# WorkBuddy 3.12.0

## 修改说明

### 新增：DSH 控制台全屏沉浸

- 进入「助手 → DSH 内核」默认进入全屏：
  - 隐藏 App 顶栏（DSH 内核 / 网关信息 / 日志 / 重启）与底部 6 Tab 导航；
  - 隐藏系统状态栏与手势条（从边缘上滑可临时唤出），控制台占满整屏；
  - 全屏态按 `WindowInsets.displayCutout` 避让挖孔 / 刘海，无开孔机型是纯整屏。
- 顶部居中新增浮动 **「退出全屏」** 按钮：点一下回到 App 界面（顶栏 + 底部导航恢复），
  继续用其它 Tab；DSH 顶栏同时新增「全屏使用」按钮，可随时再进入全屏。
- 系统返回键优先退出全屏，不会一按就退出 App。
- 进出全屏只改变布局约束，**不会重建 WebView**：对话、输入框草稿、滚动位置都保留。
- 全屏状态保存在当前会话内，切到别的 Tab 再回来依旧是全屏。

### 优化：整体卡顿与掉帧

1. **重写 WebView 视口修复脚本**（掉帧主因）
   旧脚本在 `document.documentElement` 上监听 `childList+subtree`：聊天流式输出时每个 token
   都会重置 350ms 定时器，随后全量遍历所有样式表 + 所有 `[style]` 元素做 `setProperty`，
   等于周期性强制整页样式重算。现在：
   - 高度只在视口尺寸真的变化时更新（`ResizeObserver` + 高度去重）；
   - `vh → px` 全量换算只在首帧执行一次；
   - SPA 运行时新增的 `<style>` 只补丁新增节点，不再全量扫描整页。
2. **WebView 渲染开销**
   - 底色由透明改为不透明：少一层整屏 alpha 混合；
   - 开启 `offscreenPreRaster`（长会话滚动更稳）、关闭 overscroll 与滚动条；
   - 页面主题色回调直接改 WebView 背景与系统栏图标，不再回传 Compose 状态，
     主题切换不再触发整屏重组与 WebView 重新布局。
3. **日志限流**：release 包不再逐条把前端 `console.log` 写进 logcat（只保留告警 / 错误，
   300ms 限流）；流式输出时渲染线程不再被日志 I/O 拖慢。debug 包保持全量。
4. **WebView 及时释放**：离开 DSH 页 / 内核重启时 `stopLoading + removeView + destroy`，
   反复进出不再累积渲染进程与 JS 堆，长时间使用后的整体变慢得到缓解。
5. **重组范围收敛**：`agentClient` / `gatewayStatus` 只在原生助手分支订阅，
   DSH 页不再跟着网关状态变化整屏重组。
6. **轮询更省**
   - 静默轮询结果与旧值相等时不写状态，不再每 5 秒把整张列表重组一遍；
   - `quiet` 刷新不再拨动 `refreshing`，下拉刷新指示器不会周期性闪烁；
   - 轮询绑定生命周期：后台不打接口，回前台立即静默刷新一次。

### 版本与验证

- `versionCode 28` / `versionName 3.12.0`，与 3.11.x 同签名，可直接覆盖安装。
- 构建验证：`:app:assembleRelease` 通过；`testDebugUnitTest` 58 项全部通过。
- 本机没有连接真机，未做帧率实测；全屏与掉帧改动以代码路径与构建验证为准，
  建议安装后重点体验：DSH 对话流式输出时滚动、长按输入框打字、进出全屏、
  切换 Tab 后返回控制台。
